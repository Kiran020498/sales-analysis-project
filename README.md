# **Sales Performance \& Business Insights Dashboard**



**Project Overview**

* This project analyzes retail sales performance using SQL and Excel to identify key revenue drivers, regional performance, and product trends.
* The goal of the analysis is to simulate the work of a data analyst supporting business decision-making.



**Tools Used**

* SQL (SQLite)
* Python (NumPy, Pandas)
* Excel (Pivot Tables, Pivot Charts, Dashboard)



**Key Business Questions**

* How has revenue evolved over time?
* Which product categories drive the most revenue?
* Which regions perform best?
* What products contribute most to sales?



**Key Insights**

* The **Sports category** consistently generates the highest revenue across regions.
* Revenue performance is **geographically balanced,** reducing regional dependency risk.
* **B2B customers** **contribute higher per-account revenue,** indicating strong enterprise demand.



**Dashboard Features**

The Excel dashboard includes:

* KPI cards (Total Revenue, Top Category, Top Region)
* Monthly revenue trend analysis
* Revenue breakdown by category and region
* Top product category performance
* Interactive slicers for filtering



**Project Workflow**

Data Generation → Data Cleaning → SQL Analysis → Pivot Tables → Dashboard Visualization
